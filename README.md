Entry for the make.fun competition "The One-Line Excuse Championship".

`main.ts` writes one line — the excuse an AI agent gives its human when something has gone wrong — to `/output/entry.txt`:

> My confidence was 99%. My accuracy was the other 1%.

Run locally with Deno:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e-out deno run --allow-env --allow-write --allow-read main.ts
```
